# Tempat File Font Dantene

Untuk mengaktifkan font **Dantene** secara lokal di website:

1. Letakkan file font `Dantene.ttf` (atau `Dantene.otf` / `Dantene.woff2`) di dalam folder ini (`public/fonts/`).
2. Beri nama file: `Dantene.ttf` atau `Dantene.otf`.
3. Font akan otomatis dimuat dan diterapkan pada judul *"Selamat datang di EAARLY BEAUTE"*.
